# 數字與門檻速查

> [!warning] 使用原則
> SAA **不是背數字的考試**，絕大多數題目考的是選型判斷。但有一類題目會**用數字當篩選器**（「執行需要 20 分鐘」→ 排除 Lambda；「保留 45 天」→ 排除 Glacier Flexible）。這頁只收**真的會影響選項排除**的數字，刻意不收「知道也用不到」的配額。
>
> 數字可能隨 AWS 更新調整，考前以 [[官方資料]] 為準。Day 25 掃這頁即可，不要提早背。

## 考試本身

| 項目 | 數值 |
|---|---|
| 題數 / 時間 | **65 題 / 130 分鐘**（平均 120 秒/題） |
| 計分題 / 測試題 | **50 / 15** |
| 通過分數 | **720 / 1000** |
| Domain 權重 | 安全 **30%**、韌性 **26%**、效能 **24%**、成本 **20%** |

## 運算

| 項目 | 數值 | 為什麼重要 |
|---|---|---|
| **Lambda 最長執行** | **15 分鐘** | **超過就不能用 Lambda** → Fargate / Batch / Step Functions |
| Lambda 記憶體 | 128 MB – **10 GB** | CPU 隨記憶體等比增加 |
| Lambda `/tmp` | 512 MB – **10 GB** | 需大量暫存檔時 |
| Lambda 部署包 | 250 MB（解壓後）/ **10 GB**（容器映像） | 大型相依套件的選擇 |
| Lambda 預設併發 | 每帳號每 Region **1,000** | 併發不足題 |
| **Spot 中斷通知** | **2 分鐘** | 應用必須能在 2 分鐘內優雅結束 |
| **EC2 On-Demand 計費粒度** | 秒（Linux，最低 60 秒） | |
| Reserved / Savings Plans 期間 | **1 或 3 年** | |
| 最大折扣量級 | RI/SP 約 **72%**、Spot 約 **90%** | 成本題的相對比較 |

## 網路

| 項目 | 數值 | 為什麼重要 |
|---|---|---|
| **VPC CIDR 範圍** | **/16 ~ /28** | 規劃題 |
| **每個 subnet AWS 保留** | **5 個 IP** | `/24` 實際可用 **251** 個，不是 256 |
| Security Group | **stateful**；只有 allow | 回程自動放行 |
| NACL | **stateless**；有 allow 與 deny；**按規則編號由小到大** | 必須開回程 ephemeral port |
| **Gateway endpoint 支援服務** | **只有 S3 和 DynamoDB** | 其他一律 interface endpoint |
| NAT Gateway 頻寬 | 自動擴展至 **45 Gbps** | |
| **VPC Peering** | **不支援遞移路由** | 多 VPC 要選 TGW |
| Site-to-Site VPN | **每連線 2 條隧道**，每隧道約 1.25 Gbps | HA 設計 |
| Direct Connect | 1 / 10 / 100 Gbps；**不加密** | 要加密需疊 VPN 或 MACsec |
| Route 53 TTL | 自訂；影響 failover 速度 | 要秒級切換改用 Global Accelerator |
| **Multivalue answer 回傳上限** | **8 筆** | |

## 儲存

| 項目 | 數值 | 為什麼重要 |
|---|---|---|
| **S3 物件大小** | 0 B – **5 TB** | |
| **單次 PUT 上限** | **5 GB** | 超過必須用 **multipart upload** |
| Multipart 建議門檻 | **> 100 MB** 建議、**> 5 GB** 強制 | |
| **S3 耐久性** | **99.999999999%（11 個 9）** | |
| S3 Standard 可用性 | 99.99% | One Zone-IA 為 99.5% |
| **最低儲存期間** | Standard-IA / One Zone-IA **30 天**；Glacier Instant / Flexible **90 天**；**Deep Archive 180 天** | 提前刪除仍要付滿 |
| Glacier Deep Archive 取回 | **數小時（約 12–48 小時）** | 不能用在需要快速取回的題目 |
| **EBS volume 範圍** | 1 GiB – 64 TiB（依類型） | |
| **EBS Multi-Attach** | 僅 **io1/io2**、同 AZ、最多 **16** 台、需 cluster-aware FS | 不是共享檔案系統 |
| HDD 類型（st1/sc1） | **不能當開機碟** | |
| EFS | 自動擴展，**無容量上限** | |

## 資料庫

| 項目 | 數值 | 為什麼重要 |
|---|---|---|
| **RDS 自動備份保留** | **0 – 35 天**（0 = 關閉） | PITR 範圍 |
| RDS read replica | 一般最多 **5 個**（依引擎） | |
| **Aurora 儲存副本** | **3 個 AZ × 2 份 = 6 份** | 耐久性說明 |
| Aurora 儲存上限 | 自動擴展至 **128 TB** | |
| **Aurora replica 數** | 最多 **15 個** | |
| **Aurora Global Database** | 主 1 + 次要最多 5 個 Region；**RPO ≈ 1 秒、RTO ≈ 1 分鐘** | 跨 Region DR 題的關鍵數字 |
| **DynamoDB item 大小** | **400 KB** | 大物件要放 S3 存指標 |
| DynamoDB PITR | 過去 **35 天** | |
| **DynamoDB GSI 一致性** | **只支援最終一致性讀** | 強一致需求不能靠 GSI |
| ElastiCache Redis | 支援 Multi-AZ 自動故障切換 | Memcached 不支援 |

## 訊息與串流

| 項目 | 數值 | 為什麼重要 |
|---|---|---|
| **SQS 訊息大小** | **256 KB** | 更大要用 S3 + Extended Client Library |
| **SQS 保留期** | 預設 **4 天**，最長 **14 天** | |
| **Visibility timeout** | 預設 **30 秒**，最長 **12 小時** | 太短會導致**重複處理** |
| **Long polling 等待** | 最長 **20 秒** | 降低空回應與成本 |
| SQS delay | 最長 **15 分鐘** | |
| **FIFO 去重窗** | **5 分鐘** | |
| **Kinesis shard 寫入** | **1 MB/s 或 1,000 records/s** | 容量規劃題 |
| **Kinesis shard 讀取** | **2 MB/s**（共享）；Enhanced Fan-Out **每 consumer 2 MB/s** | |
| **Kinesis 保留期** | 預設 **24 小時**，最長 **365 天** | 重播能力 |
| **Firehose 緩衝** | 最低約 **60 秒** | 這就是它「近即時」的原因 |
| **Step Functions Standard** | 最長 **1 年** | |
| **Step Functions Express** | 最長 **5 分鐘** | |
| SNS 訊息大小 | 256 KB | |

## 安全

| 項目 | 數值 | 為什麼重要 |
|---|---|---|
| **KMS 金鑰刪除等待期** | **7 – 30 天** | 期間可取消 |
| KMS 直接加密上限 | **4 KB** | 更大需 envelope encryption |
| KMS CMK 自動輪替 | 每年 | |
| **CMK 的 Region 範圍** | **Region 專屬** | 跨 Region 複寫加密資料需 multi-Region key 或目的地金鑰 |
| **CloudFront 的 ACM 憑證** | 必須簽發在 **us-east-1** | 常考 |
| IAM role 預設 session | 1 小時（可設 1–12 小時） | |
| Shield Standard | **免費、自動啟用** | |

## 治理

| 項目 | 數值 | 為什麼重要 |
|---|---|---|
| **SCP 不適用於** | **管理帳號（management account）** | 所以管理帳號不放工作負載 |
| CloudTrail 事件歷史 | 主控台可查最近 **90 天** | 更長需送 S3 或用 CloudTrail Lake |
| **CloudTrail data events** | **預設關閉**且另外收費 | 要稽核 S3 物件層級存取必須啟用 |
| **Placement group – Spread** | 每 AZ 每群組最多 **7 台** | |
| **Placement group – Partition** | 每 AZ 最多 **7 個 partition** | |
