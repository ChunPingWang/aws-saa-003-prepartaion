# 出題頻率校準

> [!abstract] 這篇要解決什麼問題
> 這份 vault 原本的「高頻 / 低頻」標記是**憑經驗判斷**的。後來用一份 **684 題的第三方模擬題庫**做統計，發現有 **10 個我標為高頻的服務，實際出現率低於 2%**。
> 這一頁記錄實測數據，用來**校準時間分配**——讀書時間該按證據分配，不是按直覺。

> [!warning] 三個必須先講清楚的限制
> **① 這是一份題庫，不是官方考題。** 統計反映的是該題庫的偏好，與實際考卷有落差。
> **② 統計的是「出現在選項中」，不是「是正解」。** 該題庫沒有標答案。出現在選項代表「你必須有能力判斷它」——包含當干擾項。
> **③ 低頻 ≠ 可以不讀。** 見下方「為什麼安全類服務看起來很低」。

## 🔍 幾個反直覺的發現

> [!important] ① CloudWatch 比 ALB、SQS、API Gateway 都高
> **8.2%**，排在第八。但本 vault 把它放在 [[成本與可觀測性]] 的一個段落裡。
> 讀的時候要提高權重：**agent 才收記憶體指標、metric filter + alarm、subscription filter** 這三項是重點。

> [!important] ② DataSync（4.4%）比 Athena（4.2%）還高
> 遷移類服務的出現率被低估了。[[遷移與混合雲]] 原本被歸為可壓縮的主題，但 DataSync + Storage Gateway + Snow + DMS **合計超過 13%**。

> [!important] ③ 「不要反射選 EKS」被數據證實了
> **ECS 5.6% vs EKS 1.9%**——ECS 出現率是 EKS 的 **三倍**。
> [[決策樹 運算選型]] 裡「題幹沒點名 Kubernetes 就不要選 EKS」這條建議，有實測支持。

> [!danger] ④ 我原本高估了這些
> **Amazon MQ 0.3%、PrivateLink 0.4%、Placement group 0.4%、IAM Identity Center 0.6%、Step Functions 1.2%、Savings Plans 1.2%。**
> 這些在本 vault 裡都有完整段落甚至決策樹條目。**內容留著（觀念仍正確），但不要在它們身上花太多複習時間。**

## ⚖️ 為什麼安全類服務看起來很低？

GuardDuty 1.9%、Macie 1.8%、Security Hub 0.4%——但 **Domain 1（安全）佔 30%**，這不矛盾：

**安全題大多不點名這些服務。** 它們考的是 **IAM policy 怎麼評估、加密金鑰權限、網路邊界怎麼切**——在統計裡分別落到 `IAM role 4.5%`、`KMS 5.4%`、`VPC endpoint 6.0%` 這些項目上。

> [!tip] 正確的讀法
> **服務出現率**衡量的是「要不要記得這個服務叫什麼、做什麼」。
> **Domain 權重**衡量的是「這類問題會考幾題」。兩者要分開看。
> 安全類的**機制**（權限評估、加密、邊界）要熟；安全類的**產品名**（GuardDuty/Inspector/Macie）只要能一句話分辨即可——那正是 [[威脅偵測與邊界防護]] 用一張對照表處理的原因。

## 🎯 題幹限定詞的實測頻率

這比服務頻率更有行動價值——**它告訴你哪一種「篩選條件」最常出現**：

| 限定詞 | 出現率 | 對應的排除邏輯 |
|---|---:|---|
| **LEAST operational overhead** | **13.5%** | 砍掉自建、EC2、EKS、土炮腳本 |
| **MOST cost-effective / LOWEST cost** | **11.8%** | **先用其他條件篩，剩下的才比價** |
| highly available | 8.5% | 多 AZ；沒說跨 Region 就別選 Region 級 |
| encryption / encrypted | 5.4% | KMS、傳輸中 vs 靜態、跨 Region 金鑰 |
| scalable / scalability | 5.3% | 水平擴展、解耦、託管服務 |
| fault-tolerant / resilient | 2.9% | Spot 可用、多 AZ、重試與 DLQ |
| real-time / near real-time | 2.6% | Kinesis 對 Firehose 的分界 |
| disaster recovery / RPO / RTO | 2.6% | 先用 RTO 篩再比價 |
| MOST secure | 1.6% | 最小權限、私有路徑、不用長期金鑰 |
| minimal downtime | 0.9% | Multi-AZ、DMS CDC、藍綠部署 |
| minimal code change | 0.7% | Amazon MQ、EFS/FSx、RDS |

> [!danger] 前兩名合計約 25%
> **四題就有一題**在問「維運負擔最低」或「成本最低」。
> 這兩個詞的排除邏輯練熟，報酬率高於多背十個服務。詳見 [[常見陷阱與誘答選項識別]] Part 1。
