# 選型比較與常見陷阱

| 題目條件 | 優先比較 | 核心差異 |
|---|---|---|
| Web path/host vs TCP/UDP | ALB / NLB | L7 路由 vs L4 連接 |
| Stateful vs stateless filter | SG / NACL | ENI 層 stateful allow vs subnet 層 stateless allow/deny |
| Internet 入站 vs private 出站 | IGW / NAT gateway | 直接對外可達條件 vs private 出站轉換 |
| 少量 VPC vs hub 網路 | Peering / TGW | 點對點 vs 集中路由 |
| S3/DynamoDB 私網 vs 其他支援 API | Gateway / Interface endpoint | 路由表 endpoint vs ENI/PrivateLink endpoint |
| 全球內容快取 vs 非快取網路入口 | CloudFront / Global Accelerator | CDN vs anycast 加速 |
| Object / block / file | S3 / EBS / EFS | API、單主機磁碟、共享 NFS |
| 即時 vs 封存 | S3 Standard / IA / Glacier | 存取頻率、取回時間與費用 |
| 一般 RDS HA vs 讀取擴展 | Multi-AZ DB instance / read replica | standby failover vs readable replica；DB cluster 另論 |
| SQL vs key-value vs cache | RDS/Aurora / DynamoDB / ElastiCache | 交易與查詢模型不同 |
| DynamoDB 加速 vs 通用 cache | DAX / ElastiCache | DynamoDB 專用 vs Redis/Valkey 等用途 |
| 排隊 vs 廣播 vs 事件路由 | SQS / SNS / EventBridge | 持久消費、fan-out、規則路由 |
| VM/containers/functions | EC2 / ECS/Fargate / Lambda | 控制、持續工作量、時間限制及維運 |
| 專線 vs VPN | Direct Connect / Site-to-Site VPN | 專用連線 vs 網際網路加密隧道 |
| DR 策略 | Backup / Pilot light / Warm / Active-active | 預置程度、恢復速度、成本與複雜度 |

## 以你的背景特別注意

- K8s 熟悉不代表任何容器題都選 EKS；題目若強調低維運，評估 ECS/Fargate 或 Lambda。
- Step Functions 可做 workflow，但業務 SAGA 補償、冪等、交易邊界仍要設計。
- RDS Multi-AZ **DB cluster** 有 reader；不要套用標準 Multi-AZ DB instance 的不可讀 standby 結論。
- S3 gateway endpoint 提供私有網路路徑，並不授予 `s3:GetObject`。
- ASG 保證容量/健康替換，不保證資料狀態；共享狀態需要外部化。

# 補充比較（2026-09-27 新增）

原表已涵蓋核心比較，以下補上新增主題的對照與幾組高頻但原本缺漏的比較。

## 安全服務

| 題目條件 | 優先比較 | 核心差異 |
|---|---|---|
| 威脅行為 vs 已知漏洞 vs 敏感資料 | GuardDuty / Inspector / Macie | 行為異常 / CVE 掃描 / **S3 內的 PII** |
| 彙整 vs 調查 | Security Hub / Detective | 集中呈現 findings / 根因關聯分析 |
| L7 內容 vs VPC 流量 vs 端口 | WAF / Network Firewall / SG | HTTP 規則 / 全協定 IDS-IPS / ENI 端口來源 |
| 託管金鑰 vs 專屬硬體 | KMS / CloudHSM | 多租戶託管 / **單租戶 FIPS 140-3 L3** |
| 有無自動輪替 | Secrets Manager / Parameter Store | **內建輪替（付費）** / 無輪替（免費） |
| 預防 vs 偵測 | SCP / AWS Config | **事前阻止** / 事後發現與修正 |
| 動作 vs 狀態 vs 表現 | CloudTrail / Config / CloudWatch | 誰呼叫了 API / 資源設定 / 效能指標 |

## 身分

| 題目條件 | 優先比較 | 核心差異 |
|---|---|---|
| App 終端使用者 vs 公司員工 vs 工作負載 | Cognito / IAM Identity Center / IAM Role | **千萬別為終端使用者建 IAM user** |
| 認證 vs 取得 AWS 憑證 | Cognito User Pool / Identity Pool | 登入拿 JWT / 換 STS 臨時憑證 |
| 既有 AD 代理 vs AWS 上的完整 AD | AD Connector / Managed Microsoft AD | 不儲存目錄資料 / 獨立目錄可建信任 |
| 帳號層上限 vs 身分建立上限 | SCP / Permission boundary | OU/帳號範圍 / 限制某身分能授出的權限 |

## 分析與串流

| 題目條件 | 優先比較 | 核心差異 |
|---|---|---|
| 佇列 vs 串流 vs broker | SQS / Kinesis Data Streams / Amazon MQ | 消費即刪 / **多消費者可重播** / **AMQP-JMS 相容** |
| 即時 vs 近即時 | Kinesis Data Streams / Data Firehose | 毫秒-秒、自寫 consumer / **≥60 秒、零維運交付** |
| 臨時查詢 vs 資料倉儲 vs 全文檢索 | Athena / Redshift / OpenSearch | S3 上 SQL 按掃描計費 / OLAP 叢集 / 搜尋與日誌 |
| ETL vs 查詢引擎 | Glue / Athena | 轉換與 **Data Catalog** / 查詢 |

## 遷移與混合

| 題目條件 | 優先比較 | 核心差異 |
|---|---|---|
| 搬家 vs 延伸 | DataSync / Storage Gateway | 搬完就不用本地 / **本地持續以傳統介面存取雲端** |
| 線上 vs 實體運送 | DataSync / Snow Family | 頻寬夠 / **頻寬不足、PB 級** |
| 伺服器 vs 資料庫 | MGN / DMS | 整台 lift-and-shift / 資料庫（含異質 + SCT） |
| 保留 SFTP 介面 | Transfer Family | 外部夥伴的工作流程不變 |
| 本地區塊裝置在雲端 | Volume Gateway **Cached** / **Stored** | 主資料在雲省本地空間 / 主資料在本地低延遲 |

## 運算與擴展

| 題目條件 | 優先比較 | 核心差異 |
|---|---|---|
| 彈性折扣 vs 鎖定折扣 | Compute SP / EC2 Instance SP / Standard RI | **涵蓋 Fargate 與 Lambda** / 鎖 family+Region / 鎖規格 |
| 隔離硬體 vs 可見 socket | Dedicated Instance / Dedicated Host | 合規隔離 / **BYOL 按 socket-core 授權** |
| 低延遲 vs 分散故障 vs 拓樸感知 | Cluster / Spread / Partition placement group | HPC 同機架 / 關鍵少量分散 / HDFS-Kafka-Cassandra |
| 消除冷啟動 vs 隔離額度 | Provisioned concurrency / Reserved concurrency | 預先初始化 / 保留並限制併發 |
| 容器拉不到映像 vs 應用 403 | Task execution role / Task role | 基礎設施權限 / 應用程式權限 |

## 其他高頻

| 題目條件 | 優先比較 | 核心差異 |
|---|---|---|
| 根網域指向 ALB/CloudFront | **Alias** / CNAME | **只有 Alias 能用在 zone apex** |
| 延遲最佳 vs 法規在地 | Latency-based / Geolocation routing | 效能 / **合規與語言** |
| IPv4 只出不進 vs IPv6 只出不進 | NAT Gateway / **Egress-only IGW** | NAT 不處理 IPv6 |
| 連線數耗盡 vs 讀取壓力 | RDS Proxy / Read Replica | 連線池 / 分攤讀取 |
| 不可變備份 | S3 Object Lock **Compliance** / Governance | **連 root 都不能刪** / 特權可繞過 |

## 常見陷阱補充

- **Multi-AZ ≠ DR**（同 Region）；**Read Replica ≠ HA**（不自動切換）；**備份 ≠ 高可用**。
- **WAF 掛不上 NLB**；要擋 L7 攻擊得用 ALB 或前置 CloudFront。
- **Gateway endpoint 只有 S3 與 DynamoDB**，且**從 on-prem 經 DX 存取 S3 不能用它**。
- **VPC Peering 不支援遞移路由**。
- **Lambda 15 分鐘上限**是硬篩選器。
- **S3 各類別的最低儲存期間**會讓「單價最低」變成「總價最貴」。
- **`AccessDenied` 是權限問題**，不要用網路方案去解（反之 timeout 不要用 IAM 去解）。
- **未完成的 multipart upload 會持續計費**且在物件清單中看不到。
- **CloudWatch 預設沒有記憶體與磁碟可用空間指標**，需要 agent。
- **CloudFront 的 ACM 憑證必須在 us-east-1**。
- **KMS CMK 是 Region 專屬的**，跨 Region 複寫加密資料要處理目的地金鑰。
- 題目沒說 Kubernetes 就**不要選 EKS**；沒說順序就**不要選 FIFO**；沒說跨 Region 就**不要選 Region 級方案**。
