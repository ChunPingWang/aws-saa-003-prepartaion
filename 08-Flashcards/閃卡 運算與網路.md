## 🖥 運算選型

Lambda 的最長執行時間？::**15 分鐘**（超過就要改用 Fargate / Batch / Step Functions）

Lambda 的記憶體範圍？::128 MB – 10 GB，**CPU 隨記憶體等比增加**

為什麼調大 Lambda 記憶體有時反而更便宜？::CPU 隨記憶體等比增加，執行時間縮短後總計費（GB-秒）可能更低

`provisioned concurrency` 解決什麼問題？::**冷啟動**——預先初始化執行環境並保持溫熱

`reserved concurrency` 解決什麼問題？::**併發隔離**——為某函式保留額度（同時也是上限），避免它吃光帳號配額

Lambda 非同步呼叫失敗後預設重試幾次？之後呢？::重試 **2 次**，之後事件被**丟棄**；要保留必須設 DLQ 或 Lambda Destinations

SAA 容器題什麼時候才選 EKS？::**只有題幹出現 Kubernetes / kubectl / Helm / 既有 K8s 工作負載 / multi-cloud portability 時**

ECS 拉不到 ECR 映像是哪個角色權限不足？::**task execution role**（基礎設施代表你做的事）

容器內應用呼叫 S3 得到 403 是哪個角色？::**task role**（應用程式自己的權限）

EKS 上讓 Pod 取得 AWS 權限的機制？::**IRSA（IAM Roles for Service Accounts）** 或 EKS Pod Identity——不是給節點 instance role

CloudFront Functions vs Lambda@Edge 怎麼選？::簡單 header/URL 改寫、極低延遲、超高請求量 → **CloudFront Functions**；需要存取網路、處理 body、較長執行 → Lambda@Edge

## 💰 EC2 購買模式

`fault-tolerant`、`can be interrupted`、`flexible start time` → 選什麼？::**Spot**（最高約 90% 折扣，中斷前有 **2 分鐘**通知）

Compute Savings Plans 相對 EC2 Instance Savings Plans 多了什麼？::跨 instance family、跨 Region、跨 OS，而且**涵蓋 Fargate 與 Lambda**

BYOL 且授權按實體 socket 計算 → 選什麼？::**Dedicated Host**（只有它看得到 socket/core）

Dedicated Instance 與 Dedicated Host 的差別？::兩者都是專用硬體，但**只有 Dedicated Host 讓你看見 socket/core 數量**，所以 BYOL 必選 Host

On-Demand Capacity Reservation 有折扣嗎？::**沒有**。它只保留容量，可與 Savings Plans 疊加才有折扣

「降低成本但要維持基本可用性」的標準答案？::ASG **mixed instances policy**：基準 N 台 On-Demand + 其餘 Spot

## 📍 Placement Group

`lowest latency / highest throughput between instances`、HPC → 哪種 placement group？::**Cluster**（同一 AZ、鄰近硬體；代價是 AZ 故障全滅）

「少量關鍵實例要避免同時故障」→ 哪種？::**Spread**（每 AZ 每群組最多 **7 台**）

HDFS / Kafka / Cassandra 這類拓樸感知的分散式系統 → 哪種？::**Partition**（每 AZ 最多 **7 個 partition**）

HPC/MPI 用哪種網路介面？::**EFA**（Elastic Fabric Adapter），一般網路加速是 ENA

## ⚖️ 負載平衡與擴展

ALB、NLB、GWLB 各在 OSI 哪一層？::ALB = **L7**（HTTP/HTTPS/gRPC）；NLB = **L4**（TCP/UDP/TLS）；GWLB = **L3**（IP 封包）

哪一種 ELB 有靜態 IP？::**NLB**（每 AZ 一個靜態 IP，可指定 EIP）。ALB 只有 DNS 名稱

WAF 可以掛在哪些資源上？::CloudFront、ALB、API Gateway、AppSync、Cognito User Pool、App Runner、Verified Access——**不包含 NLB**

「NLB 後面的服務要擋 SQL injection」怎麼辦？::前面加 **CloudFront**（掛 WAF）或改用 **ALB**

ASG 的 health check type 預設是什麼？有什麼後果？::預設 **`EC2`**，只看 instance status check。應用當掉但 OS 活著時**不會替換**——要改成 **`ELB`**

「終止實例前要先上傳日誌」用什麼？::**ASG lifecycle hook**（在 `Terminating` 狀態暫停）

「應用啟動要 10 分鐘，擴容太慢」用什麼？::**warm pool** 或 **predictive scaling**

ASG cross-zone load balancing 在 ALB 與 NLB 的預設值？::**ALB 預設開啟且免費；NLB 預設關閉**，開啟後跨 AZ 流量計費

「使用者在擴縮後被登出」的最佳解與次佳解？::最佳 = **session 外部化到 ElastiCache/DynamoDB**；次佳 = ALB **sticky session**（節點故障仍會掉）

「部署時 in-flight 請求被中斷」用什麼？::**deregistration delay（connection draining）**

## 🌐 VPC 與網路

VPC CIDR 的大小範圍？::**/16 到 /28**

每個 subnet AWS 保留幾個 IP？`/24` 實際可用幾個？::保留 **5 個**；`/24` 只剩 **251** 個

Security Group 與 NACL 的三個差別？::SG 在 **ENI**、**stateful**、只有 allow；NACL 在 **subnet 邊界**、**stateless**、有 allow 也有 deny（要開回程 ephemeral port）

Gateway endpoint 支援哪些服務？::**只有 S3 和 DynamoDB**。其他一律 interface endpoint

Gateway endpoint 與 interface endpoint 的費用差別？::**gateway endpoint 免費**；interface endpoint 按小時 + 資料處理量計費

為什麼「on-prem 經 Direct Connect 私有存取 S3」不能用 gateway endpoint？::gateway endpoint 只是 **VPC 路由表裡的一筆路由**，只在 VPC 內生效；正解是 **S3 interface endpoint** 或 Public VIF

IPv6 的私有資源要「只出不進」用什麼？::**Egress-Only Internet Gateway**（NAT gateway 只處理 IPv4）

NAT gateway 高可用要怎麼部署？::**每個 AZ 各一個**，各 AZ 私有路由表指向自己 AZ 的 NAT（同時省跨 AZ 傳輸費）

VPC Peering 支援遞移路由嗎？::**不支援**。A-B、B-C 通不代表 A 能到 C；要遞移得用 **Transit Gateway**

PrivateLink 相對 Peering/TGW 最大的優勢？::**CIDR 可以重疊**，而且只暴露單一服務而非整個 VPC

Direct Connect 有加密嗎？::**沒有**。要加密得疊 **Site-to-Site VPN** 或用 MACsec

「需要專線但要立即可用」怎麼辦？::**先用 VPN 過渡，DX 建置完成（數週到數月）後再切換**

Site-to-Site VPN 每個連線有幾條隧道？::**2 條**

on-prem 要解析 VPC 私有 DNS 用什麼？反過來呢？::進來 → **Inbound Resolver Endpoint**；出去 → **Outbound Resolver Endpoint + 轉發規則**

VPC Flow Logs 記錄什麼？不記錄什麼？::記錄連線中繼資料與 **ACCEPT/REJECT**；**不含封包內容（payload）**

## 🌍 DNS 與全球流量

Route 53 的七種 routing policy？::Simple、Weighted、Latency-based、Failover、Geolocation、Geoproximity、Multivalue answer（+ IP-based）

Latency-based 與 Geolocation 的分界？::**Latency = 誰快去誰那（效能）**；**Geolocation = 誰在哪去哪（合規/語言/data residency）**

`example.com` 這個根網域要指向 ALB，用 Alias 還是 CNAME？::**只能用 Alias**。DNS 標準禁止 CNAME 用在 zone apex

Multivalue answer 最多回傳幾筆？::**8 筆**（通過健康檢查的）

CloudFront 與 Global Accelerator 的三個分界點？::**可快取 HTTP → CloudFront**；**非 HTTP 協定 / 需要固定 anycast IP / 需要不受 DNS 快取影響的秒級切換 → Global Accelerator**

CloudFront 用的 ACM 憑證必須在哪個 Region？::**us-east-1**（維吉尼亞北部）。ALB 則用 ALB 所在 Region 的憑證

CloudFront 讓 S3 origin 保持私有用什麼？::**OAC（Origin Access Control）**。OAI 是舊機制，新設計一律用 OAC

Signed URL 與 Signed Cookie 的差別？::Signed **URL** = 單一檔案；Signed **Cookie** = 多個檔案（如整個影片串流目錄）

「origin 失敗時自動改用備援 origin」用什麼？::CloudFront **origin group**
